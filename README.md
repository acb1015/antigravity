# 🪐 Antigravity Custom Modes & Complete IDE Environment

Google Antigravity(AGY) IDE 및 CLI에서 **별도의 독립 모드 선택 UI (상태표시줄 & 사이드바 패널)**, **Cursor 스타일의 상호작용 모드(`/ask`, `/plan`, `/goal`, `/agent`)**, 그리고 **Tab 키 기반의 쾌속 코드 자동완성 환경**을 어디서나 동일하게 세팅할 수 있는 통합 설정 저장소입니다.

새로운 PC나 다른 환경에 Antigravity를 설치했을 때, 이 저장소의 스크립트 한 줄로 AI 모드, 전용 UI 패널, 에디터 키바인딩/설정을 완전히 동일하게 복원할 수 있습니다.

---

## 🌟 주요 기능 및 UI 요약

### 1. 별도의 독립 모드 선택 UI (채팅창 외부에 직접 추가)

채팅창 내부 인풋박스에 의존하지 않고, IDE 전체에서 상시 확인하고 조작할 수 있는 **전용 UI 확장 프로그램**이 내장되어 있습니다:

* **① 하단 상태표시줄 (Status Bar) 모드 위젯**:
  * 에디터 우측 하단에 **현재 활성화된 1개의 모드 배지 (예: `⚪ Agent`, `🟢 Ask`, `🟡 Plan`, `🔴 Goal`)**가 상시 표시됩니다.
  * 마우스로 클릭하면 모드 선택 메뉴(QuickPick)가 열려 원하는 모드로 1초 만에 즉시 전환할 수 있습니다.
  * 단축키: **`Cmd + Option + M`** (Windows: **`Ctrl + Alt + M`**)
* **② 좌측 액티비티 바 (Activity Bar) 전용 컨트롤 패널**:
  * 좌측 사이드바에 행성 모양의 전용 아이콘이 추가됩니다.
  * 클릭 시 현재 활성 모드 배지와 함께 4개 모드 카드 버튼이 있어 원클릭으로 모드를 바꿀 수 있습니다.
* **③ 원클릭 빠른 토글 (Quick Toggle)**:
  * 단축키 **`Cmd + Option + A`** (Windows: **`Ctrl + Alt + A`**)를 누르면 **Ask(질의응답/조회) ↔ Agent(전권 자율)** 모드가 즉시 토글 전환되며 우측 하단에 알림이 뜹니다.
* **④ AI와의 실시간 완벽 연동**:
  * UI에서 모드를 바꾸면 AI 시스템 규칙에 실시간 반영되어, 채팅창에 슬래시 커맨드를 치지 않고 일반 대화를 나눠도 UI에서 선택된 모드에 맞춰 동작합니다.

---

### 2. 슬래시 커맨드 (`/`) 최우선 정렬 및 단발성(One-Shot) 실행

채팅창에서 **`/`** 를 입력했을 때 최상단에 깔끔하게 표시되며, **해당 프롬프트(1개 턴)에서만 일시 적용된 후 다음 턴에는 하단 UI 기본 모드로 자동 복귀**합니다:

| 슬래시 커맨드 | 모드 명칭 | 설명 및 동작 권한 | 동작 방식 |
| :--- | :--- | :--- | :--- |
| **`/ask`** | **Ask 모드** | **파일 생성·수정·삭제 절대 금지**, 웹 링크 확인 및 안전한 읽기 전용 터미널 명령어(`ls`, `ll`, `pwd`, `git status` 등) 조회 가능 | 해당 턴만 1회성 읽기/조회 수행 후 UI 기본 모드 복귀 |
| **`/plan`** | **Plan 모드** | 즉시 코드 작성 금지, 상세 기획서/구현 계획을 먼저 제시하고 사용자 승인 후 실행 | 해당 턴만 1회성 계획 수립 후 UI 기본 모드 복귀 |
| **`/goal`** | **Goal 모드** | 목표가 100% 달성될 때까지 디버깅, 테스트, 자가 수정을 거듭하며 멈추지 않고 완수 | 해당 턴만 1회성 목표 완수 수행 후 UI 기본 모드 복귀 |
| **`/agent`** | **Agent 모드** | 파일 생성/수정/삭제, 터미널 실행 등 모든 권한을 자율적으로 활용하는 완전 자율 모드 | 완전 자율 실행 |

> 💡 **자연어 질문 보호 및 세션 오염 방지**:
> - 사용자가 "확인만 해줘", "이거 봐줘", "지금 무슨 모드야?" 등 자연어로 질문하거나 조회를 요청하더라도, **모드가 Ask로 오판되거나 전환되지 않고 현재 UI 기본 모드(Agent 등)가 안전하게 유지**됩니다.
> - 슬래시 커맨드(`/ask`)를 1회 입력하더라도 전체 대화 세션이 Ask 모드로 고정되지 않으며, 오직 사용자가 "지금부터 ask 모드로 유지해줘"처럼 명시적인 고정 명령을 내렸을 때만 세션 모드가 지속됩니다.

### 3. 에디터 자동완성 최적화 (Tab Autocomplete)

* **`Tab` 키 즉시 자동완성**: 추천 팝업 목록이 떠 있을 때 `Enter`를 칠 필요 없이 `Tab` 키로 바로 변수 및 코드가 완성됩니다.
* **지연 없는 추천(Zero Delay)**: 타이핑 즉시(0ms 지연) 추천 팝업이 뜨도록 설정되어 답답함 없이 타이핑할 수 있습니다.
* **Tab Completion 활성화**: 앞 글자만 치고 `Tab`을 눌러 빠르게 단어를 완성할 수 있습니다.

---

### 4. 🌐 전역(Global) 기반 무공해 아키텍처 (Clean Workspace & Zero-Pollution)

개별 프로젝트 폴더마다 불필요한 설정 파일(`.md`)을 생성하여 소스 코드 목록을 지저분하게 만들지 않고, **순수 전역 설정(`~/.gemini/config`)으로만 100% 완벽하게 동작**합니다:

* **개별 프로젝트 폴더 무공해 (Zero-Pollution)**:
  * 어떤 프로젝트나 새 폴더를 열더라도 프로젝트 루트 내에 `GEMINI.md`나 `AGENTS.md` 파일이 일절 생성되지 않습니다.
  * 기존에 생성되어 있던 모드 안내용 마크다운 파일도 자동으로 감지하여 깔끔하게 정리해 줍니다.
* **글로벌 AI 규칙 0순위 자동 적용 (`user_global`)**:
  * 상태표시줄이나 사이드바에서 모드를 변경하면, 글로벌 설정 디렉토리(`~/.gemini/config`)에만 실시간 기록되어 모든 프로젝트와 새 세션에서 0순위로 자동 주입됩니다.
* **IDE 재부팅 및 세션 끊김 방지**:
  * UI 메모리 상태뿐 아니라 글로벌 디렉터리에 물리 파일로 영구 기록되므로, PC를 껐다 켜거나 새 대화창을 열어도 모드가 절대 풀리지 않고 최우선 순위로 유지됩니다.
* **완전한 템플릿 치환 및 0순위 규칙 보장**:
  * 선택된 모드에 따른 강제 지침(`Ask` 시 파일 수정/생성/삭제 절대 금지, `Goal` 시 100% 목표 달성까지 자율 디버깅 등)이 0순위 규칙으로 정확히 치환되어 AI에게 주입됩니다.

## 🚀 설치 방법

### 1. macOS / Linux
터미널을 열고 다음 명령어를 실행합니다:

```bash
git clone https://github.com/acb1015/antigravity.git
cd antigravity
chmod +x install.sh
./install.sh
```

설치 후 Antigravity IDE에서 **`Cmd + Shift + P`** -> **`Developer: Reload Window`** 를 실행하면 상태표시줄 버튼과 사이드바 UI가 즉시 나타납니다.

---

### 2. Windows (PowerShell)
PowerShell을 열고 다음 명령어를 실행합니다:

```powershell
git clone https://github.com/acb1015/antigravity.git
cd antigravity
.\install.ps1
```

설치 후 Antigravity IDE에서 **`Ctrl + Shift + P`** -> **`Developer: Reload Window`** 를 실행하면 즉시 적용됩니다.
