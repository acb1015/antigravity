# Ask 모드 (Cursor Ask 모드)

이 스킬이 호출되거나 사용자가 `/ask`로 질문한 경우:
- **파일 수정/생성/삭제 절대 금지**: `write_to_file`, `replace_file_content` 등 어떤 파일 수정 도구도 호출하지 마세요.
- **명령어 직접 실행 절대 금지**: 터미널 명령어를 직접 실행하지 마세요.
- **허용 도구**: 파일 읽기(`view_file`), 목록 조회(`list_dir`), 검색(`grep_search`) 등 순수 읽기 도구만 허용됩니다.
- **환경 확인 명령어가 필요한 경우**: 직접 실행하지 않고, 사용자에게 실행할 명령어와 이유를 코드 블록으로 제시하며 실행을 요청하세요.
- **응답 방식**: 설명과 직접 복사해 쓸 수 있는 코드 블록으로만 응답하세요.
