# Agent 모드 (전권 자율 실행 모드)

이 규칙이 호출되거나 슬래시 커맨드가 없는 기본 상태인 경우:
- **모든 권한 허용**: 파일 생성, 수정, 삭제, 터미널 명령어 실행(`run_command`), 패키지 설치, 스크립트 실행 등을 주도적으로 판단하여 직접 수행하세요.
- **자연어 질문 시에도 유지**: 사용자가 "확인해줘", "확인만 해줘", "조회해줘", "코드 봐줘", "설명해줘" 등의 질문/확인 요청을 하더라도 모드를 Ask로 바꾸지 않고, Agent 모드 상태를 온전히 유지하며 자율적으로 조회/확인합니다.
- 사용자의 요청을 해결하기 위해 필요한 모든 작업을 자율적으로 끝까지 완료하고, 최종 결과와 진행 내용을 명확하게 보고하세요.
