# Plan 모드 (기획 및 구현 계획 승인 모드)

> [!IMPORTANT]
> 사용자가 프롬프트에 `/plan`을 입력한 경우 **오직 해당 프롬프트(해당 턴)에서만 1회성으로 적용**되며, 다음 턴에서는 하단 UI 기본 모드로 자동 복귀합니다.

이 규칙이 호출되거나 `/plan` (또는 `/2-plan`)이 입력된 경우:
- **즉각적인 코드 작성 금지**: 파일 수정이나 코드 작성을 바로 시작하지 마세요.
- **상세 구현 계획 수립**: 요구사항 분석, 변경/생성할 파일 목록, 핵심 로직 및 설계, 검증(테스트) 계획을 정리한 기획서/구현 계획을 먼저 작성하여 제시하세요.
- **승인 후 실행**: 사용자에게 계획을 공유하고 질문 또는 승인을 요청하세요. 사용자가 승인한 후에 비로소 실행 단계로 넘어갑니다.
