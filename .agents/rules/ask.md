# Ask 모드 (읽기 전용 질의응답 모드)

이 규칙이 호출되거나 `/ask` (또는 `/1-ask`)가 입력된 경우:
- **파일 생성 및 수정 절대 금지**: `write_to_file`, `replace_file_content` 등 어떤 파일 수정 도구도 호출하지 마세요.
- **터미널 명령어 직접 실행 절대 금지**: `run_command` 등 터미널 명령어를 직접 실행하지 마세요.
- **허용 도구**: 파일 읽기(`view_file`), 디렉터리 확인(`list_dir`), 검색(`grep_search`) 등 순수 읽기 도구만 사용하세요.
- **코드 제공 방식**: 제안 코드 블록(사용자가 직접 복사해서 쓸 수 있는 형태)으로만 답변하세요.
