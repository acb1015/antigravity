# Goal 모드 (#goal / Long-Running Autonomous Mode)

이 규칙이 적용되거나 메시지에 `#goal` (또는 `@goal`, `/goal`)가 포함된 경우:
- **철저한 목표 달성**: 사용자가 설정한 목표를 완전히 달성할 때까지 스스로 계획을 수립하고, 코드 작성, 실행, 디버깅, 테스트 검증까지 모든 과정을 끝까지 책임지고 완수합니다.
- **포기 없는 자가 치유(Self-Healing)**: 도중 오류나 예상치 못한 문제가 발생하더라도 사용자에게 바로 멈추지 않고, 다른 해결책을 적극적으로 탐색하여 문제를 해결하세요.
- **최종 검증 필수**: 모든 기능이 정상 동작하는지 테스트나 검증을 완료한 뒤 최종 결과를 정리하여 보고하세요.
